# Photo Puzzle

A Python puzzle game that lets you turn your own photos into puzzles. Choose a difficulty and drag the pieces into the correct positions.

**Features**
- Custom photos
- Multiple difficulty levels
- Preview and grid options
- Timer

**Requirements:** Python 3, Pygame, Pillow

**Installation**
```bash
pip install pygame Pillow
```

**Run the game**
```bash
python photo_puzzle.py
```

**Controls:** P = Preview · G = Grid · R = Restart
